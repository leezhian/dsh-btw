# btw side chat（侧边聊天）

ChatGPT「临时聊天」式的 btw：`btw <问题>` 在右栏开一个临时对话，界面即主会话同款
Conversation，用完关闭即消失，与主会话上下文完全隔离。

## 用法

- 主输入框 `btw <问题>`（或输入框左侧 `btw` 按钮）→ 右栏打开临时对话，问题作为首条消息
- 界面为**原生 Conversation**（官方 sidebar-chat 同款挂载：`SessionProvider` +
  `conversation.content` 工厂）——真实的附件、权限切换、模型切换、发送/停止，
  不进入"新会话"选工作区界面，直接空上下文开聊
- 关闭标签页 = 丢弃（取消 + 归档，含 `btw-closed` 落盘标记）；下次 `btw` 全新
- 每个主会话一条独立支线：在 A 会话开 `btw` 不影响 B 的支线；同一会话内并发
  `btw` 合并为一次操作
- 打开失败显示重试按钮；重启后遗留的 btw 标签会被自动清扫关闭（无僵尸面板）
- 切换主会话保留支线（tab 留在原会话布局）；面板内重排不误杀（重挂载取消窗口）

## 隔离机制

- 支线是普通会话（主会话 cwd、无工作区、无子代理、无目录）：结构上零回灌，
  主会话子代理徽标不增长，创建零模型调用（无默认开场提问）
- 每个主会话一条活跃支线，互不串用；`btw` 永远新开（打开前先丢弃旧支线）

## 降级

原生挂载若运行时抛错（错误边界捕获）或框架 props 缺失，自动降级到自绘面板
（含流式对话、图片附件、本地化权限/模型切换、关闭即弃）。

## 已知限制

- 开着期间出现在侧栏「未分组」一行；关闭归档后即消失
- 归档后会话 log 文件仍留在磁盘（DSH 仅提供归档，无物理删除）
