# btw side chat（侧边聊天）

ChatGPT「临时聊天」式的 btw：`btw <问题>` 在右栏开一个临时对话，用完关闭即消失，
与主会话上下文完全隔离。

## 四条核心语义

1. **开**：主输入框 `btw <问题>`（或输入框左侧 `btw` 按钮）→ 右栏出现临时对话；
   带问题文本时自动作为首条消息发出
2. **用**：普通会话 + 原生 Conversation 界面（附件 / 权限 / 模型 / 发送齐全），
   创建零模型调用——没有默认开场提问
3. **关**：关闭标签页 = 丢弃（取消回合并归档），从所有列表消失；下次 `btw` 全新
4. **隐**：与主线零关联（无子代理、无目录、无回灌通道）。开着期间在侧栏「未分组」
   占一行（已知取舍），关闭即无痕

每个主会话各有一条活跃支线，互不串用。

## 实现

- **Client**（client.js）：自建右栏 tab（协议 `btwchat`，蓝本为官方 ui-subagent 的
  sidebar-chat）——resource provider retain 普通会话，`SessionProvider` + 
  `conversation.content` 工厂渲染原生界面；`btw` 命令流（watermark 去重）驱动开合；
  tab 清单驱动关闭即弃（含重启后恢复的遗留 tab）
- **Host**（index.js）：仅注册 `/btw` 命令 + 一次性归档 v0.3 遗留子代理（徽标归零）
  + 针对遗留子代理的结算通知防护

## 已知限制

- 开着期间出现在侧栏「未分组」一行；关闭归档后即消失
- 归档后会话 log 文件仍留在磁盘（DSH 仅提供归档，无物理删除）
- 完全不可见的临时会话需要平台一等支持（sessions.create 的不列出/临时标记），
  插件层无法实现
