# btw side chat（侧边聊天）

ChatGPT「临时聊天」式的 btw：在右栏开一个临时对话，界面即主会话同款
Conversation，用完关闭即消失，与主会话上下文完全隔离。

## 入口与用法

- **入口有两个**：主输入框 `/btw`（纯客户端命令：菜单行带插件图标、本地化名称
  「侧边聊天」与 `btw` 别名；不向主会话写入任何记录）和右侧面板「开始」页的
  「侧边聊天」卡片
- 打开后直接是**原生 Conversation**（官方 sidebar-chat 同款挂载）——真实的附件、
  权限切换、模型切换、发送/停止；不进入“新会话”选工作区界面，空上下文直接开聊，
  想问什么在侧边聊天里输入即可
- **关闭标签页 = 丢弃**（取消 + 归档，含 `btw-closed` 落盘标记）；下次 `/btw` 全新
- **每个主会话各持一条独立支线**：在 A 会话开不影响 B 的支线；同一会话内并发
  `btw` 合并为一次操作
- 切换主会话时支线保留（标签留在原会话布局）；面板内重排不误杀（重挂载取消窗口）
- 打开失败显示重试按钮；重启后遗留的 btw 标签会被自动清扫关闭（无僵尸面板）

## 隔离机制

- 支线是普通会话（主会话 cwd、无工作区、无子代理、无目录登记）：结构上零回灌，
  主会话子代理徽标不增长，创建零模型调用（无默认开场提问）
- `/btw` 是客户端命令贡献（`ctx.commandUi.register`）：裸调用不提交任何内容，
  主会话日志零记录

## 降级

原生挂载若运行时抛错（错误边界捕获）或框架 props 缺失，自动降级到自绘面板
（含流式对话、图片附件、本地化权限/模型切换、失败重试、关闭即弃）。

## 已知限制

- 开着期间出现在侧栏「未分组」一行；关闭归档后即消失
- 归档后会话 log 文件仍留在磁盘（DSH 仅提供归档，无物理删除）
- `/btw` 不接受任务文本参数（客户端命令只消费裸调用）；任务在侧边聊天里输入
- 宿主侧保留的 v0.3 遗留子代理防护会拦截那些旧子代理的结算通知（新架构无此通道）
